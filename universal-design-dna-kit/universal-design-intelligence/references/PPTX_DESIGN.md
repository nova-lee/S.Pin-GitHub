# 프레젠테이션(PPTX) 표준

목표는 회사 템플릿이 아니라 글로벌 기업의 전략 보고서·제품 소개서·컨설팅 제안서 수준의 덱이다. 모든 슬라이드는 **편집 가능한 네이티브 요소**로 만든다.

## 원칙

- **One Slide, One Message.** 슬라이드 제목은 주제("시장 현황")가 아니라 결론 문장("중견 제조사의 Copilot 도입은 파일럿에서 멈춘다")이다. 제목만 이어 읽어도 이야기가 되어야 한다.
- 본문은 제목을 증명하는 근거만. 근거가 없는 슬라이드는 합치거나 지운다.
- 밀도는 목적에 맞춘다: 발표용(투영)은 슬라이드당 30단어 안팎, 배포용(읽는 덱)은 120단어까지 + 출처 각주.
- 내용을 줄이는 것이 아니라 전달력을 높이는 방향으로 재구성한다: 문단 → 구조(비교표, 프로세스, 2×2), 수치 나열 → 차트 하나.

## 그리드와 타이포 (16:9, 13.333 × 7.5in)

- 여백: 좌우 0.6in, 상단 0.5in, 하단 0.45in. 12열 그리드, 열 간격 0.2in.
- 제목 영역 고정: 모든 본문 슬라이드에서 같은 위치·크기. 제목 위에 섹션 아이브로우(`overline`, 10~11pt)를 둘 수 있다.
- 크기: 표지 40~54pt(`display-lg` 비율), 슬라이드 제목 24~28pt Bold, 본문 14~16pt, 표·차트 라벨 11~12pt, 출처 각주 9pt. 투영용 덱에서 12pt 미만 본문 금지.
- 서체: Pretendard(설치 또는 임베드) — 대체: 맑은 고딕. 숫자 정렬이 중요한 표는 표 형식 숫자를 지원하는 서체를 유지한다. 한 덱에 서체 2종 이하.
- 색: 바탕 흰색 또는 `canvas`, 텍스트 `ink`/`ink-secondary`, 강조는 `accent` 하나. 표지·간지·결론은 `surface-inverse` 바탕을 쓸 수 있다. 슬라이드 테마 색(Theme Colors)에 토큰을 등록해 사용자가 팔레트에서 고를 수 있게 한다.

## 레이아웃 — 같은 구조를 반복하지 않는다

Cover · Executive Summary · Full-bleed Visual · Split(5/7, 4/8) · Editorial(큰 인용 + 근거) · Data Visualization · Timeline · Process Flow · Architecture Diagram · Comparison(표) · Strategy Framework(2×2, 피라미드는 금지 — 구조가 실제로 위계일 때만) · Roadmap · Case Study · Conclusion / Next Step.

- 연속된 3장이 같은 레이아웃이면 하나를 바꾼다.
- 아이콘+제목+설명 3열 카드는 최대 덱당 한 번.

## 편집 가능성 우선순위

1. 네이티브 텍스트 상자(자동 맞춤 끔, 고정 크기 + 여유 공간)
2. 네이티브 도형(직사각형·선·화살표) — 다이어그램은 도형과 커넥터로
3. 네이티브 표
4. 네이티브 차트(엑셀 데이터 포함 — 숫자를 고칠 수 있게)
5. 편집 가능한 다이어그램(그룹화된 도형)
6. 외부 이미지 — 사진·제품 화면·3D 렌더에만

슬라이드 전체 또는 텍스트·차트·다이어그램을 이미지로 넣지 않는다. 슬라이드 마스터와 레이아웃을 정의해 사용자가 새 슬라이드를 같은 규칙으로 추가할 수 있게 한다.

## 데이터와 다이어그램

- 차트 하나에 메시지 하나: 강조 계열만 `accent`, 나머지는 회색(`data-2`, `data-3`). 범례 대신 직접 라벨. 3D 차트·파이 3조각 초과·이중 축 금지.
- 모든 수치에 출처와 기준 시점을 각주로. 추정치는 "추정"이라고 표기한다.
- 다이어그램의 모든 화살표는 실제 흐름(데이터, 순서, 책임)을 뜻해야 한다. 장식 화살표·장식 원 금지.
- 아키텍처 다이어그램은 실제 구성 요소 이름(예: Copilot Studio, Dataverse, Azure AI Search)과 경계(테넌트, 네트워크)를 정확히.

## 검수

슬라이드 노트 포함 모든 텍스트 맞춤법 · 제목만 읽어서 이야기가 되는지 · 글자 넘침(대체 서체 기준) · 같은 요소의 위치 일관성(제목, 페이지 번호, 각주) · 수치와 출처 대조 · 렌더 이미지로 전 슬라이드 확인.

# 에셋 & 이미지 표준

이미지와 그래픽은 완성도를 가장 크게 좌우한다. 한 장의 나쁜 이미지가 정교한 레이아웃 전체를 템플릿처럼 보이게 만든다.

## 품질 기준

- **해상도**: 표시 크기의 2배(레티나). 히어로는 최소 2560px 폭, 원본은 무손실 보관.
- **비율**: 16:9(히어로·슬라이드), 16:10(카드 미디어), 4:5(인물·세로), 1:1(썸네일)만. 한 그리드 안에서 비율을 섞지 않는다.
- **구도**: 피사체 하나, 충분한 여백, 텍스트가 올라갈 자리를 비워 둔다. 텍스트를 이미지 위에 올리면 대비 4.5:1을 확인한다(필요하면 이미지 쪽을 어둡게 — 그라데이션 오버레이 대신 이미지 자체 보정).
- **조명·색**: 한 페이지의 이미지는 같은 색온도·같은 콘트라스트·같은 채도로 보정한다. 브랜드 accent와 충돌하는 강한 색은 피한다.
- **재질·질감**: 제품·공간은 실제 재질이 보이는 촬영 또는 PBR 렌더.

## 선택 기준

| 필요 | 우선 | 금지 |
|---|---|---|
| 제품 기능 설명 | 실제 제품 화면 캡처(실제 데이터 또는 명시된 예시 데이터) | 그려낸 가짜 대시보드 |
| 하드웨어·공간 | 실제 촬영, 실제 3D 렌더 | 일반 스톡 |
| 사람 | 실제 고객·팀 사진(동의 받은 것) | 악수·하이파이브 스톡, AI 생성 인물 |
| 추상 개념 | 타이포그래피와 레이아웃만으로 해결 | 전구·톱니·로켓 일러스트 |
| 분위기·컨셉 시안 | AI 생성 이미지(컨셉 단계에서, 출처 표기) | 최종 산출물에서 실제 제품·데이터·기능을 대신하는 AI 이미지 |

- AI 생성 이미지는 분위기 표현과 내부 시안에만 쓴다. 실제 제품 화면, 실제 데이터, 실제 기능, 편집 가능해야 하는 디자인 요소(차트, 다이어그램, UI)를 이미지로 대체하지 않는다.
- 저작권·초상권·상표: 사용 권한이 확인된 이미지만. 다른 회사 로고는 허락받은 고객 로고 월에만.

## 일관성

- 한 페이지(한 덱) 안에서 사진·일러스트·3D 렌더를 섞지 않는다. 섞어야 하면 영역을 분리한다.
- 일러스트가 필요하면 한 사람(한 스타일)이 그린 세트만. 아이콘은 한 계열 하나.
- 로고는 원본 파일(SVG)을 복사해 쓴다. 다시 그리거나 근사하지 않는다. 로고가 없으면 텍스트 워드마크로 두고 공백을 표시한다.

## 파일 규칙

- 웹: AVIF → WebP → JPEG 순, `srcset` 3단계(1x·1.5x·2x), 아이콘·로고는 SVG(최적화, `currentColor`).
- 3D: GLB(Draco/Meshopt), 텍스처 KTX2, 정지 폴백 이미지 동봉.
- 비디오: H.264 MP4 + WebM, 무음 자동재생은 8초 이하 루프, 포스터 이미지 필수, reduced-motion에서 정지.
- PPTX: PNG(UI 캡처)·JPEG(사진), 슬라이드 크기의 2배 해상도, 압축은 220ppi.
- 파일명: `영역-내용-변형@배율.확장자`(예: `hero-agent-console-dark@2x.avif`). 모든 이미지에 대체 텍스트를 함께 작성한다.

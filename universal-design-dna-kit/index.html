03 CHOOSE YOUR MODE

어떤 작업이든,
딱 맞는 모드로.

궁금한 것을 물어보고, 실행 전에 계획을 세우고, 구현은 에이전트에게 맡겨보세요. VS Code의 Copilot Chat에서 작업에 맞게 선택할 수 있습니다.

01 / EXPLORE

질문하고 이해하기

Ask mode

코드와 기술에 관해 질문하고 설명이나 코드 제안을 받습니다. 프로젝트를 이해하거나 아이디어를 탐색할 때 적합합니다.

이렇게 물어보세요

“이 함수가 어떻게 동작하는지 설명해줘.”

02 / DESIGN

구현 전에 설계하기

Plan mode

프로젝트를 살펴보고 필요한 질문을 거쳐 구현 계획을 만듭니다. 코드를 변경하기 전에 단계와 검증 방법을 검토하세요.

이렇게 물어보세요

“로그인 기능을 추가할 구현 계획을 세워줘.”

03 / BUILD

작업을 맡기고 완성하기

Agent mode

목표를 전달하면 관련 코드를 살펴보고 파일 수정과 명령 실행 등 여러 단계를 수행하며 결과를 검증합니다.

이렇게 물어보세요

“로그인 기능을 구현하고 테스트해줘.”

VS Code 기준 예시입니다. 모드와 기능의 제공 여부는 IDE, 버전 및 조직 정책에 따라 다릅니다. 에이전트의 도구 사용은 승인 설정을 따르며 결과는 직접 검토하세요.
